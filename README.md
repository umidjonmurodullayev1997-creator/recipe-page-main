## 🛠 Built with

- Semantic HTML5 markup (`<main>`, `<article>`, `<section>`, `<table>`)
- CSS custom properties & Flexbox
- **Sass (SCSS)** preprocessor with `@use "sass:math"` and custom `rem()` conversion functions
- Responsive Media Queries (`@media`)
- Google Fonts (`Young Serif` and `Outfit`)

---

## 💡 What I Learned & Key Takeaways

Working on this project helped me solidify several core frontend concepts:

1. **Sass Functions & Variables:** Creating reusable `@function rem($px)` helpers using `sass:math` alongside structured HSL color variables for scalable and maintainable styling.
2. **Custom List & Marker Styling:** Styling `<ul>` and `<ol>` elements using `list-style-position` and the `::marker` pseudo-element to customize list bullet/number colors and typography.
3. **Semantic Table Layout:** Building and styling a clean nutritional table using `border-collapse: collapse`, targeted row borders (`:last-child`), and distinct typographic hierarchy.
4. **Typography & Design Accuracy:** Combining serif headings (`Young Serif`) with sans-serif body text (`Outfit`) and matching spacing, border radii, and colors accurately to the design specifications.
